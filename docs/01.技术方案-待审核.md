- **主要理论依据**：[Mnih 等，Human-level control through deep reinforcement learning，Nature 2015](../Human-level%20control%20through%20deep%20reinforcement%20learning.pdf)，重点参照正文与 Methods 中的 Q 学习目标、经验回放、独立目标网络、评估及消融。
- **课程补充材料**：本地 PPT/4-DQN.pdf 与 PPT/5-DQN改进.pdf，用于对齐课堂讲解的函数逼近、主网络与目标网络、均匀回放和平方 TD 误差。PPT 目录尚未纳入公开仓库；它不替代主论文。
- **实现参考**：[patrickloeber/snake-ai-pytorch](https://github.com/patrickloeber/snake-ai-pytorch) 与 [billodalroy/Snake-Game-Deep-Reinforcement-Learning](https://github.com/billodalroy/Snake-Game-Deep-Reinforcement-Learning)。是否符合主论文以实际代码和论文正文核对，不依据 README 标题推断。
- **已确认的研究方向**：迁移并验证 DQN 关键机制，贯通 MDP 建模 → 算法学习 → 实验效果。七部分方向与 03、04 的若干选择见 [决策记录](PROJECT_DECISIONS.md)。

本项目研究**贪吃蛇中的 DQN 机制**。原论文研究 Atari 2600 游戏；本项目不声称复现其 49 款游戏成绩或“达到人类水平”。Double DQN、Dueling DQN 和 PER 在汇报中解释，不列入必做训练。下面所有贪吃蛇规则、输入编码、工程接口和实验数值均为**本项目工程或实验设计**。

## 01｜项目定位

**论文方法**：从游戏画面学习动作价值，在多款 Atari 游戏中使用同一 DQN 学习框架，并分析经验回放、目标网络等组件。

**参考代码**：第一份是贪吃蛇教学实现；第二份提供 DQN、DDQN、A2C notebook。它们帮助理解游戏与训练代码，但均不等于论文实验。

**本项目选择**：以论文 DQN 的稳定学习机制为主线，在一个可控的贪吃蛇任务中做基线与消融。相比直接照搬 Atari 像素网络，这更适合课程时间和算力；相比同时实现多种算法，更能回答指定论文的核心问题。代价是输入与任务不同，报告必须清楚标出迁移范围。

## 02｜游戏环境

**论文方法**：使用 Atari 模拟器和原有游戏得分，没有规定贪吃蛇规则。**参考代码**：第一份将 Pygame 显示和游戏步进放在一起；第二份 notebook 使用网格并可选显示。

**本项目工程设计（参数待审核）**：

| 项目 | 提案 |
| --- | --- |
| 默认棋盘 | 10 × 10 单元格；尺寸作为配置参数，同一次实验固定 |
| 初始状态 | 长度为 3 的直线蛇，在合法位置和朝向中按种子抽样；食物在空格中均匀抽样 |
| 每步动作 | 直行、左转、右转；先改变朝向，再移动一个格子 |
| 碰撞 | 撞墙或撞自身结束；未吃食物时蛇尾同步移走，因此进入即将腾出的尾格应视为合法 |
| 食物与胜利 | 吃到食物后蛇增长，食物从剩余空格均匀产生；填满棋盘则结束并记为成功 |
| 步数上限 | 每回合最多 4 × 宽 × 高步，默认 400 步；达到上限标记为截断，与碰撞分开统计 |
| 显示 | 规则计算不依赖窗口；训练可无界面运行，评估回放可选画面 |

优先选择独立网格规则，是为了可复现、便于测试并支持多次实验。默认尺寸和步数上限需要审核；不直接复制任何参考仓库中的奖励或超时常数。

## 03｜MDP 建模

**论文方法**：Atari 模拟器内部状态不可见，论文用观察与动作历史形式化状态，并把最近四帧预处理后送入网络。**参考代码**：第一份使用 11 项局部特征；第二份 DQN notebook 使用位置、食物偏移、长度和近期动作构成的向量。两者均未完整呈现有顺序的蛇身。

**本项目 MDP 设计**：

| 要素 | 已确认方向与待审核提案 |
| --- | --- |
| 状态 s | 有顺序的蛇身位置、食物位置、朝向、剩余步数。棋盘尺寸由本次实验配置给定 |
| 观察 o | 3 个 10 × 10 网格通道：蛇头二值、食物二值、蛇身次序值；另加朝向 one-hot 4 维与剩余步数比例 1 维 |
| 蛇身次序编码 | 蛇头单独标记；蛇身第 j 节从颈部的 j=1 开始，以 (蛇长−j)/蛇长赋值，确保尾格也非零并保留先后顺序 |
| 动作 a | 直行、左转、右转，共 3 个相对动作 |
| 转移 P | 移动与碰撞规则确定；吃到食物后的新食物位置在空格中均匀随机抽样 |
| 奖励 R | 吃到食物 +1，碰撞 −1，其他移动 0；填满棋盘时仅获得最后一份食物奖励，不另设胜利奖金 |
| 折扣 γ | 0.99 |
| 结束 | 撞墙、撞自身或填满棋盘为游戏终止；固定步数上限为单独标记的截断 |

有序蛇身、食物、朝向和剩余步数决定下一步的条件分布，因此比仅有局部危险标记更适合论证马尔可夫性。种子用于生成可复现实验，不作为智能体输入。奖励保持事件驱动，不加入距离食物的塑形项，以免把额外奖励设计与 DQN 机制消融混在一起。

本提案把步数上限视为任务的有限时域边界，剩余步数进入状态。达到上限时记录截断原因，但训练目标不跨过回合边界继续自举；这项处理需要审核时特别确认。

## 04｜DQN 算法

**论文方法**：卷积网络预测每个动作的 Q 值；ε-greedy 探索，均匀经验回放，在线网络学习，独立目标网络每隔 C 步硬同步。论文 Atari 实验使用 84 × 84 × 4 图像输入、RMSProp、奖励截断和 TD 误差截断。**课件方法**：主网络、目标网络、均匀回放、平方 TD 误差和定期同步。**参考代码**：第一份采用向量输入、MLP、Adam 和回放，但没有独立目标网络；第二份的 DQN notebook 也使用向量与 MLP，DDQN notebook 的做法不应写成主论文 DQN。

**本项目算法设计**：保留论文的经验回放、独立目标网络及硬同步，按已确认选择使用轻量 CNN、MSE 和 Adam。这是 DQN 机制迁移，优化器与损失配置不声称与论文完全相同。

| 组件 | 待审核提案 |
| --- | --- |
| Q 网络输入 | 3 个网格通道，加朝向 4 维和剩余步数比例 1 维 |
| CNN | 3→16 通道的 3×3 卷积、padding 1、ReLU；16→32 通道的 3×3 卷积、步幅 2、padding 1、ReLU |
| 输出头 | 卷积特征展平后拼接 5 个标量，经 128 单元全连接层和 ReLU，输出 3 个动作 Q 值；不加 softmax |
| 探索 | ε 按环境步数从 1.0 线性降至 0.05，前 50,000 步完成退火；之后保持 0.05 |
| 回放 | 最近 50,000 条转移，均匀采样；收集 2,000 条后开始学习，batch size 64 |
| 更新 | 每 4 个环境步做一次梯度更新；每 1,000 次梯度更新把在线网络参数复制到目标网络 |
| 优化 | Adam，学习率 1×10⁻⁴；MSE 只计算本次选择动作的 Q 值与目标的差 |
| 折扣与训练 | γ = 0.99；每次训练运行 200,000 个环境步，具体预算见第 05 部分 |

对转移 (s, a, r, s′)，若下一状态不是终止或本项目有限时域的截断边界，目标为 y = r + γ maxₐ′ Q目标(s′, a′)；否则 y = r。目标计算不反向传播，训练损失为批次平均 [Q在线(s, a) − y]²。这个公式体现课件的基础 DQN；不用在线网络选动作、目标网络评估动作的 Double DQN 目标。

与主论文相比，本项目输入是有序语义网格而非 Atari 像素帧，网络更小，回放容量和训练步数也更小；MSE + Adam 是用户确认的课程适配。报告将分别说明这些差异，不把参考代码或课件的后续改进归入 2015 年论文方法。

网络按本次实验棋盘尺寸计算展平后的特征数；改用其他棋盘尺寸时需重新创建对应网络，不据此声称模型可直接跨尺寸泛化。

## 05｜实验设计

**论文方法**：以随机策略、人类和既有算法为参照，在多个 Atari 游戏上报告分数和学习曲线，并消融经验回放、目标网络等组件。**参考代码**：第一份绘制训练得分及均分；第二份包含多个算法 notebook 与训练/测试图。参考仓库的结果不作为本项目成绩。

**本项目实验设计（预算待审核）**：

| 组别 | 用途 | 保持或改变的条件 |
| --- | --- | --- |
| 随机策略 | 最低基线 | 三个相对动作等概率选择，不训练 |
| 简单规则策略 | 可解释基线 | 优先选不碰撞且使食物曼哈顿距离最小的动作；平局按直行、左转、右转选 |
| 完整 DQN | 主方法 | 保留回放与独立目标网络 |
| 无经验回放 | 消融 | 不建回放池；每 4 个环境步只用当步转移做一次在线更新，保持环境步数和优化步数一致 |
| 无独立目标网络 | 消融 | 自举目标改用在线网络并停止目标梯度，其他条件不变 |

- 每个 DQN 组别使用 3 个训练种子、每种子 200,000 个环境交互步，共 9 次训练、1,800,000 个训练环境步；不根据中途表现给某组额外训练步数。
- 每隔 20,000 个训练步做一次评估。评估使用与训练分离的固定 100 个种子与初始条件，动作采用贪心策略；随机和规则基线使用同一评估集。
- 环境随机数流与智能体探索随机数流分开记录；评估种子控制开局和食物抽样，避免探索抽样改变环境随机数序列。
- 主要指标：每回合吃到的食物数。辅助指标：存活步数、碰撞/填满/截断比例、训练耗时，以及固定观察集上的平均最大 Q 值。
- 展示各训练种子的单独曲线及跨种子的均值和标准差。3 个训练种子只支持初步稳定性分析，不作强统计显著性或“人类水平”结论。
- 无回放组只能使用单条新转移，因此 batch size 与完整 DQN 不同；报告须把这一差异列为消融解释的限制，不能把所有性能差异都归因于样本去相关。
- 先做短预算的运行检查，核实环境规则、日志和估值目标；这不计入正式结果。若硬件无法完成提案预算，需统一调整所有组别并在报告中说明。

独立评估种子用于测试不同开局与食物序列下的表现，不等于跨棋盘尺寸的泛化结论。若训练失败，应先检查规则、奖励和实现，再提出经审核的方案变更，不在某组上单独修改奖励。
