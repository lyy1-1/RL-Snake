# 03. 开源代码与课程 PPT 符合性复核

> 状态：静态复核结论；不是新的方案确认，也不是运行结果。核对对象为课程课件、本地未修改的上游源码及指定主论文。未安装依赖、运行代码或训练；本文件只保存在本地，等待用户明确要求后再推送。

## 核对范围与结论

- 课程依据：[3-Q_Learning.pdf](../PPT/3-Q_Learning.pdf)、[4-DQN.pdf](../PPT/4-DQN.pdf)、[5-DQN改进.pdf](../PPT/5-DQN改进.pdf)，以及用户提供的课程要求截图：讲清 **MDP 建模 → 算法学习 → 实验效果**，展示 MDP 要素、算法流程、基线、指标、消融、局限和代码或 Demo。
- 论文依据：[Mnih 等，*Human-level control through deep reinforcement learning*，Nature 2015](../Human-level%20control%20through%20deep%20reinforcement%20learning.pdf)。论文的 Atari 输入和 CNN 不能直接归为贪吃蛇代码的方法；其独立目标网络与经验回放是本项目要迁移并验证的机制。
- 主要代码依据：[patrickloeber/snake-ai-pytorch，固定提交 7ea69e6](https://github.com/patrickloeber/snake-ai-pytorch/tree/7ea69e6b79c59db731d8befc9ec174b075efc808)。本地 `snake-ai-pytorch-main/` 的核心文件此前已与该提交逐字节核对。
- 辅助代码依据：[billodalroy/Snake-Game-Deep-Reinforcement-Learning，固定提交 7145e2c](https://github.com/billodalroy/Snake-Game-Deep-Reinforcement-Learning/tree/7145e2c1b0cebd4f16ef3978b296819ea86dcd8b)。其问题见 [02. 开源代码复用评估](02.开源代码复用评估.md)。

**结论：patrickloeber 原版适合直接作为贪吃蛇环境与教学基线，但原样不能算符合课件所定义的完整基础 DQN，也不足以完成课程要求的实验验证。以它为基础做有限改动是可行路线。** 第二份仓库的 DQN notebook 同样缺少独立目标网络，且存在环境动作、奖励和运行路径方面的静态问题，不适合替代主基础。

## 对方案的直接影响

当前 [01. 技术方案（待审核）](01.技术方案-待审核.md) 的主线与复核结果一致：保留上游环境、11 特征和 MLP；补目标网络、固定 TD 目标、统一回放训练及独立实验。需在实施时特别注意三点：

1. **损失定义**：原版的三输出 MSE 形式虽可产生更新，但不能直接当作课件中对选定动作的平方 TD 误差实现；改造版应显式取所选动作的 Q 值，并阻断目标梯度。
2. **实验对照**：上游原版可作为“开源原版基线”；目标网络或回放的单因素效果应从相同的改造版分别关闭组件比较，不能用原版与改造版的成绩差直接归因。
3. **课程表述**：完整游戏状态满足我们定义的 MDP；11 项输入是局部观察。贪吃蛇环境、固定步数上限、随机种子、评估方案和 Demo 均为**本项目工程设计**。课件和主论文不提供这些贪吃蛇专用规则。

本复核没有改变 [PROJECT_DECISIONS.md](PROJECT_DECISIONS.md) 中已确认与待确认的状态；技术方案仍需用户审核后才能迁移和开发。
