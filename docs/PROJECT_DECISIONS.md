## 课程要求依据

- 应用领域可选游戏、下棋等；课件以 Atari DQN 为游戏案例。
- 论文分享需说明 MDP 建模、算法学习和实验效果：状态/观察、动作、转移、奖励、折扣、终止，采样—估值/损失—更新，选型理由、核心损失、论文改进，以及数据、基线、指标、消融、泛化、局限。
- 课程项目强调识别 MDP 要素、判断强化学习的适用性，并设计可验证的代码实验方案；准备材料包括论文和代码或 Demo。
- 以上是课程要求和评估依据，不代表已确定具体环境、算法实现或实验配置。
