## 已确认

### 01 项目定位

- **方向**：迁移并验证 DQN 关键机制，以《Human-level control through deep reinforcement learning》（Nature, 2015）为主要理论依据，将贪吃蛇作为本项目的研究任务。
- **课程主线**：贯通“MDP 建模 → 算法学习 → 实验效果”，形成能够解释建模、学习过程与实验证据的课程项目。
- **表述边界**：论文研究的是 Atari 游戏；贪吃蛇任务及其具体实现属于本项目设计，不称为论文原有实验或论文结果的直接复现。参考代码作为实现参考，算法是否符合论文以 PDF 正文和代码核对为准。
- **确认来源**：用户明确选择 B 方案，并要求贯通上述三环节。

### 02 游戏环境

- **方向**：采用独立的贪吃蛇网格规则，训练时可不显示画面，并提供可选的画面展示；网格大小可配置，随机过程可通过种子复现。
- **表述边界**：这是本项目的工程设计。原论文使用 Atari 模拟器，没有定义贪吃蛇环境；两份参考代码仅供实现参考。
- **尚待细化**：默认网格尺寸、初始化方式、超时及胜利条件等具体规则。

### 03 MDP 建模

- **方向**：以完整的结构化网格信息描述智能体所需状态，包括蛇头、有顺序的蛇身、食物与朝向；如终止条件依赖步数，状态还需包含相应计数。采用直行、左转、右转三个相对动作。奖励原则为吃到食物为正、碰撞为负、普通移动为零。
- **已确认细节**：网格编码蛇身各节的先后顺序，并附加朝向与步数信息；采用固定的回合总步数上限，达到上限时标记为截断。剩余步数应包含在智能体状态中，以便区分相同棋盘但剩余时间不同的情况。
- **表述边界**：上述贪吃蛇状态、动作和奖励均为本项目的 MDP 设计，不是论文原有定义。人工简化观察不直接称为完整马尔可夫状态。
- **尚待细化**：网格通道及数值编码、奖励数值、折扣因子、步数上限的具体值，以及截断时的学习目标处理。

### 04 DQN 算法

- **方向**：以论文 DQN 的经验回放、独立目标网络、周期性目标网络参数复制、ε-greedy 探索和 Bellman Q 学习目标为核心；网络规模适配本项目结构化输入。DDQN 不作为主算法。
- **表述边界**：迁移论文关键机制，不照搬 Atari 的像素网络和训练规模；参考代码不自动视为论文 DQN 的完整实现。
- **尚待细化**：具体网络结构、损失实现、超参数与训练预算。
- **确认来源**：用户明确确认 02–04 的推荐方案。
- **课件参照**：用户希望参考本地 `PPT/` 中的 DQN 方法；`4-DQN.pdf` 与 `5-DQN改进.pdf` 说明函数逼近、主/目标网络、均匀经验回放及 TD 更新，但没有指定 CNN/MLP 层结构或优化器，故不据此替用户确定这些选择。主论文 PDF 仍为主要理论依据。

### 05 实验设计

- **方向**：采用受控基线与关键机制消融。完整 DQN 与随机策略、简单规则策略比较，并分别检验移除经验回放或独立目标网络的影响；在相同环境交互预算下，用独立于训练的随机种子评估，并报告吃到食物数量、存活步数及多次运行的差异。
- **表述边界**：这些贪吃蛇基线、指标和消融安排是本项目实验设计，不能称为论文原有贪吃蛇实验。
- **尚待细化**：随机种子数量、交互预算、评估回合数、规则策略定义和统计呈现方式。

### 06 工程架构

- **方向**：采用小型模块化工程，分离游戏环境、DQN、训练与评估、结果绘图，确保训练和评估调用同一套环境规则，并便于小组按模块协作。
- **表述边界**：模块划分与协作流程属于本项目工程设计，原论文没有规定课程项目目录结构。
- **尚待细化**：具体目录、模块接口、配置与运行方式；在完整技术方案审核前不开始实现。
