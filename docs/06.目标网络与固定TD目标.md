## 依据与实现

主要依据为 [Nature 2015 论文](../Human-level%20control%20through%20deep%20reinforcement%20learning.pdf) PDF 第 7 页的 Methods 与 Algorithm 1，以及 [PPT/5-DQN改进.pdf](../PPT/5-DQN改进.pdf) PDF 第 5–10、18 页。

| 机制 | 当前实现 |
| --- | --- |
| 初始化 | 对在线模型做深拷贝建立 `target_model`，初始参数相同、存储独立 |
| 固定目标网络 | 目标网络设为 `eval()`，参数 `requires_grad=False`；优化器只接收在线网络参数 |
| 非终止 TD 目标 | `r + gamma * max(target_model(next_state))`，保持基础 DQN 的最大值目标 |
| 终止 TD 目标 | 仅用即时奖励，不调用下一状态的目标网络 |
| 停止目标梯度 | 在 `torch.no_grad()` 中计算目标，同时用 `pred.detach().clone()` 构造目标张量 |
| 硬同步 | 每完成 C 次 `optimizer.step()`，复制在线网络 `state_dict` 到目标网络 |

同步计数 `n_updates` 不在回合结束时清零。原版每步单样本更新算一次；回合结束的一次批量回放更新也只算一次，与批次样本数量无关。

本次保留原版三个输出上的 MSE 平均：仅已选动作的目标被替换，其他动作目标等于停止梯度后的当前预测，误差为零。这等于已选动作平方 TD 误差的平均再除以动作数 3。这里保留该缩放以减少同时发生的算法改动；后续若改为只对选中动作求 MSE，应单独记录其梯度尺度变化。

原版 `done` 同时表示碰撞和原版超时，本次按原接口继续处理；区分截断与终止尚未实现。经验回放仍是“每步新样本更新 + 每局结束回放”，因此尚未实现技术方案中统一的回放训练节奏。

## 暂定参数与运行方式

**暂定默认 C=1,000 次优化更新**，沿用此前提案的候选值，属于本项目工程配置，不是用户已确认的最终实验参数，也不是直接采用论文数值。

在项目根目录运行：

```bash
.venv/bin/python scripts/train_upstream.py --episodes 100
```

指定同步间隔：

```bash
.venv/bin/python scripts/train_upstream.py --episodes 100 --target-update-interval 1000
```

源代码默认值在 `agent.py` 的 `TARGET_UPDATE_INTERVAL`；`QTrainer` 构造函数同样提供可选参数。启动脚本通过上述参数设置 `agent.py` 的配置，并在启动信息和 `summary.json` 中记录间隔与版本 `upstream-with-target-network`，以区分之前原版运行结果。

模型仍只保存在线网络权重；当前不是包含优化器、目标网络、回放池和同步计数的完整续训检查点。启动脚本现在把最高纪录模型写到当次 `runs/upstream-时间戳/model.pth`，并在 summary 中记录路径；直接执行 `agent.py` 仍使用原版共享保存路径。

本轮首次 3 局短验证在隔离保存路径之前，触发原版保存逻辑，覆盖了 `snake-ai-pytorch-main/model/model.pth`。本轮没有事先备份该文件的旧权重；随后已修复启动脚本的保存位置，避免再次发生。该共享文件现在是短验证产生的权重，不应当作此前训练的模型使用。

## 验证

运行针对性测试，无需额外安装测试框架：

```bash
.venv/bin/python -m unittest discover -s tests -v
```

6 项测试已通过：

1. 初始参数一致但存储独立，目标网络冻结且不进入优化器。
2. 人工设置两网络不同输出，检查混合批次的目标与梯度。非终止奖励 1、gamma=0.9、目标网络最大值 4 时，目标为 4.6；不会错误使用在线网络最大值 8。
3. 单个终止样本只用奖励；即使下一状态含 NaN 也不评估它。
4. 设置 C=2，第一次优化后目标不变，第二次优化后精确同步；批量回放只计一次。
5. 拒绝零、负数和非整数同步间隔。
6. 权重保存到独立运行目录且可读取，不覆盖共享文件。

实际训练入口以默认 C=1,000 完成两次各 3 回合、最多 90 秒的短检查，均以 `completed` 状态正常退出，训练循环分别用时 8.16 秒和 6.81 秒。第二次用于检查隔离保存位置后的启动流程。达到同步边界的行为由 C=2 的数值测试验证；短运行不用于判断目标网络是否提高了得分。实验效果需要后续受控评估。
