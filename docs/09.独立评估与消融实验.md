# 09. 独立评估与消融实验

## 用现有模型比较基线

在项目根目录使用已配置的 Python 环境。将示例中的权重路径换成实际文件。

```bash
.venv/bin/python scripts/evaluate.py \
  --model saved-dqn runs/upstream-20261117-161525-325837/model.pth \
  --episodes 30 --seed-start 10000 --max-steps 1000
```

脚本同时运行随机动作、简单规则和指定模型三种策略，全部使用同一组开局种子和每局步数上限。随机策略均匀选择三个相对动作。规则策略先排除下一步碰撞的动作，再选择使蛇头离食物曼哈顿距离最近的动作。规则策略会直接读取食物坐标。DQN 冻结参数，始终选择 Q 值最大的动作。

每种策略的每一局独立设置环境种子，随机动作与食物使用不同随机数流。同种子提供相同的初始布局与随机数流。不同动作序列会改变蛇身占用和吃食物的时机，因此后来生成的食物位置可以不同。

输出在 `runs/evaluation-时间戳/`。其中 `episodes.csv` 保存逐局得分、步数、累计奖励与结束原因，`summary.json` 保存种子、权重路径与 SHA-256、每种策略的得分均值和样本标准差，`evaluation.png` 绘制得分均值和标准差。只评估一局时标准差留空。评估脚本不会启动训练。已有模型可作基线初测，正式消融应使用下述相同预算训练的权重。

## 按相同环境步数训练三个版本

```bash
.venv/bin/python scripts/train_experiment.py --steps 20000 --seed 1
.venv/bin/python scripts/train_experiment.py --steps 20000 --seed 1 --no-target-network
.venv/bin/python scripts/train_experiment.py --steps 20000 --seed 1 --no-replay
```

| 版本 | TD 目标用哪个网络 | 每次更新的数据从哪里来 |
| --- | --- | --- |
| 默认 DQN | 定期同步的目标网络 | 从经验池均匀抽样 |
| `--no-target-network` | 当前在线网络，TD 目标仍停止梯度 | 从经验池均匀抽样 |
| `--no-replay` | 定期同步的目标网络 | 最近一个批次的新经验，只用一次 |

各组在相同的环境步数更新，优化步数和批量大小一致。默认先收集 256 步，再每收集 32 步更新一次，每批 32 条。无回放组按交互顺序收集这 32 条样本，使用后清空批次。该比较涉及历史复用与随机打散这两项回放特性，报告时应说明这一点。

默认探索率按环境步数从 1.0 线性降到 0.05，衰减跨度为 10,000 步。目标网络默认每 100 次优化更新同步。环境、探索与回放使用各自的随机数流。沿用现有 11 项局部观察、游戏规则、网络结构、折扣与优化器。这些是实验脚本的可调默认值，20,000 步只是命令示例。

新训练入口在无窗口模式下运行，到请求步数时保存当时的在线权重。每次运行在 `runs/experiment-时间戳/` 下保存 `model.pth`、`summary.json`、`scores.csv` 和 `scores.png`。曲线只统计完整回合，预算落在回合中间时，摘要单独记录该回合已走的步数。环境步数预算截止不会被写成一次碰撞或游戏终止。旧的 `train_upstream.py` 按回合运行的入口仍可用于已有工作流。

## 统一评估三组并生成结果图

将下面的路径替换为上一步打印的三个运行目录。

```bash
.venv/bin/python scripts/evaluate.py \
  --model dqn runs/默认组目录/model.pth \
  --model no-target runs/无目标网络组目录/model.pth \
  --model no-replay runs/无回放组目录/model.pth \
  --episodes 30 --seed-start 10000 --max-steps 1000
```

正式汇报时，可以用多个训练种子重复三组训练，再用同一批评估种子测试各组，分别说明训练种子间的波动和测试局面间的波动。得分是每局吃到的食物数。视频继续用来展示模型行为，消融结论来自相同预算下的结果图。
